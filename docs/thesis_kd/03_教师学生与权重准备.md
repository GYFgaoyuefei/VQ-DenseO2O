# 模型与资源

| 变量 | 何时需要 |
|---|---|
| TOMATO_DATA_ROOT | 训练、验证。根目录含 images/train、images/val、annotations/instances_train.json、annotations/instances_val.json |
| THESIS_KD_M_BACKBONE_WEIGHTS、THESIS_KD_M_DETECTOR_CHECKPOINT | M 从头启动一次实验时。官方 M 为 vit_tinyplus，backbone 示例名 vittplus_distill.pt |
| THESIS_KD_S_BACKBONE_WEIGHTS、THESIS_KD_S_DETECTOR_CHECKPOINT | S 从头启动一次实验时。官方 S 为 vit_tiny，backbone 示例名 vitt_distill.pt |
| THESIS_KD_TEACHER_CONFIG、THESIS_KD_TEACHER_CHECKPOINT | 有效 KD 的固定 T0，提供其真实的 VQ-L 训练配置和权重 |
| THESIS_KD_TEACHER_VALIDATION | 写明选择该 T0 的验证集、指标、epoch 和来源记录 |
| THESIS_KD_TEACHER_STATE | 默认 ema。明确指定非 EMA 时可填 model、state_dict 或 raw |
| THESIS_KD_OUTPUT_ROOT | 默认独立工作树的 outputs/thesis_kd，可指定其安全子目录 |

可将 `local/paths.example.yml` 复制成私有 YAML，再给命令加 `--paths 路径`；顶层键为环境变量名，非空环境变量优先。原训练文件中的资源路径仅用于读取。同一 run_tag 的正式 KD 共用固定教师身份，建议同一次研究的核心与消融采用同一 tag。教师验证依据须由研究者填写，暂缺时不自动选择教师。

教师先在隔离上下文构造原生 detector 并严格装载指定分支。支持嵌套 ema.module、ema 或 model_ema 等已知布局，只有所有键均带 module. 时才统一移除。随后仅保留冻结的 backbone 和 encoder 用于 KD。每个运行记录实际权重分支、文件 SHA256、配置摘要、Validation 依据。缺少 EMA 或结构不一致会报错。教师配置不触发数据集、criterion 或优化器构建。

学生先严格加载自己的 DINO backbone，再装载本架构完整检测预训练；后者包含的参数将覆盖前者对应值。COCO 预训练与三类输出形状冲突时，仅保留新初始化的分类输出头/去噪类别嵌入，实际键清单见 run_info。所有其他缺失或不兼容参数都必须解决。网络内部标签 [0,1,2] 对应 COCO 的 1 immature、2 half、3 ripe。

M 的 encoder 为 256 通道、depth_mult 1、expansion 0.67；S 为 192 通道、depth_mult 0.67、expansion 0.34。用于原生架构测试的本仓库 VQ-L encoder 为 224 通道。指定 T0 严格装载验证的执行状态见第 09 章。
