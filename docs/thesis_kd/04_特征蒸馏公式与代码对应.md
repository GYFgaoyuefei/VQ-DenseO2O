# 编码器特征和训练目标

`StudentWrapper.forward` 调用一次原生 `detector(samples, targets=targets)`。只在当前学生 HybridEncoder 实例注册 hook，读取传给 Decoder 的三层张量。每步通过 finally 清理缓存，退出训练时移除 hook。教师直接执行 backbone 和 encoder，取同一个已增强 RGB 张量。动态位置编码支持多尺度，无空间插值。

启用集合 A 中每层都有独立 1×1 Conv2d，无 bias，注册于 DDP 和优化器构建之前。输入通道来自 Student encoder，输出通道来自 Teacher encoder。在 FP32 区域投影，保留学生梯度，教师特征 detach。

```text
L_l    = mean_B,C,H,W((P_l(F_student_l).float() - F_teacher_l.detach().float())²)
L_feat = sum(L_l for l in A) / len(A)
L      = sum(criterion(detector_outputs, targets, ...).values()) + λ_eff × L_feat
λ_eff  = λ × min(1, successful_updates / (5 × steps_per_epoch))
```

`losses.py` 只有一处公式实现。三个尺度等权，每个尺度内对所有元素取均值。单尺度实验只建一个投影，归一化分母为 1。该对照比较同一平均归一化下的尺度选择。λ 默认 1.0，是待验证初值。空 GT 图仍然参与特征 MSE；KD 关闭或配置 λ=0 时走学生基线路径。warmup 首步 λ_eff=0，投影保留在计算图中。日志区分 native、逐尺度 raw、mean、weighted、λ_eff 和 total；比较检测性能使用相应 Validation AP。

各 rank 分别冻结教师。DDP 包裹整个学生和投影模块，所有可训练参数纳入梯度裁剪。EMA 在注册 hook 之前复制原生学生。启用尺度使用同一规则加入 projector 参数组。构造教师和投影时保存恢复 Python、NumPy、Torch CPU/CUDA 的 RNG，采样器及数据 worker 单独设种子。
