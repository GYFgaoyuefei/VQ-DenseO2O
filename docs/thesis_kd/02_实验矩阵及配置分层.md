# 实验与公共训练条件

| 实验 | 学生 | 有效尺度 | 默认种子 |
|---|---|---|---|
| m_base / s_base | M / S | 无跨模型 KD | 42、0、3407 |
| m_kd / s_kd | M / S | P3、P4、P5 | 42、0、3407 |
| m_kd_p3 / m_kd_p4 / m_kd_p5 | M | 分别仅 P3、P4、P5 | 42 |
| m_kd_lambda_025 / 050 / 200 | M | P3、P4、P5 | 42，可选 |

基础实验和 KD 都保留原生 Hungarian、MAL、框定位、FGL、DDF、Mosaic、MixUp 和原生 CopyBlend。学生使用 RGB COCO 检测数据。VQ-DenseO2O、LI-CopyBlend、DC-STA、额外 mask sidecar 均未进入学生配置。

从 `configs/tomato/thesis_kd/` 的 data、models、recipes、distillation、experiments（或 ablations、sensitivity）、local 顺序合并。学生架构取本仓库对应官方模型字段，每次构建用单独的注册表副本。教师只解析用户指定的原训练配置。使用 `resolve-config` 查看完整配置、叶字段来源和 Base/KD 配对差异。开启所有尺度且 λ=1 对应核心 KD，权重探索不重复生成这项任务。

| 字段 | 共同取值 |
|---|---|
| nominal size / base_size_repeat | 640 / 6 |
| 训练轮数 / 提前停止 | 120 / 关闭 |
| train / Validation global batch | 32 / 64 |
| optimizer | AdamW，基础 LR 5e-4，DINOv3 参数 2.5e-5，decay 1e-4，norm 和 bias 零衰减 |
| 调度 | flatcosine，warmup_iter 2000，flat_epoch 60，no_aug_epoch 14 |
| 增强 | policy [7,60,106]，mixup [7,60]，copyblend [7,106]，stop 106 |
| matcher | epoch 88 切换 |
| AMP / EMA | CUDA 训练 AMP，原生 detector EMA，验证 FP32 且关闭 TF32 |

`continuous_no_rollback` 表示所有新组沿当前权重及 EMA 连续训练，通过 epoch 控制增强，不调用历史 best_stg1 回载或自适应 EMA 重启。该安排使新组彼此可比。论文中请单列旧九组与新协议。若以后更改 batch、阶段策略或选模规则，另设 protocol 与输出位置。
