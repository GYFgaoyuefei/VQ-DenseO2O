## A—F 关键算法验收

**A / Baseline：PASS。** 对照固定 beta_select commit `f92edb021fd468e354f5767bb81ac745e0347cfe` 的真实Baseline配置及源码。关闭创新后，完整检测器相同seed的每个初始化state tensor严格一致；相同合成输入的完整forward在FP32容差rtol=1e-6、atol=1e-7内一致。Matcher在epoch0/88两侧、普通main/aux/pre/encoder的原MAL与定位loss及关键梯度一致。原MixUp、CopyBlend、Mosaic的RGB/bbox/类别/area与RNG消耗通过多seed参考对照。没有合并参考分支。

**B / Mask同步：PASS。** 复用既有完整640增强管线和字段同步测试，覆盖三个seed、四个增强阶段及MixUp/CopyBlend/Mosaic/Crop/Resize/Sanitize。boxes、labels、masks、area、iscrowd、annotation_ids、visible_mask_valid、source_illumination_id与最终GT对应。固定随机选择时B0/B1的RGB、bbox、类别和原MAL不受mask-only传播影响；无效或缺失mask保留合法bbox。相对历史实现保留必要元数据同步修复，详见03迁移说明。

**C / VQ-DenseO2O：PASS。** 22项质量/原参考对照与15项criterion集成测试均通过。C、P、q_fg、q_vq、positive target与原源码逐值一致；普通MAL及关键梯度在规定FP32容差内一致。覆盖连续坐标、非整数边界、越界框原面积分母、空mask、IoU fallback、beta0原生等价、空GT、AMP、stop-gradient、ordinary四分支、DN/DN-pre及bbox/FGL/DDF保护。正式配置beta固定0.10、gamma1.5；拒绝GIoU作为质量元数据。GR类已移除正式注册，历史源码有停用说明；正式criterion不调用GR归一化。

VQ诊断使用valid_mask_ratio、fallback_ratio、q_iou_mean、q_fg_mean、q_vq_mean、q_fg_near_one_ratio、target_delta_from_native_mal等；按epoch普通匹配正样本汇总。真实数据上是否大量fallback或质量退化仍为NOT RUN，不能用合成对照推断真实监督强度。

**D / DC-STA：PASS。** 48项门控与训练接线测试通过：原8维描述符（包括原`sqrt(var+1e-8)`）、8→16→C通道MLP、10→1的3×3空间卷积、sigmoid乘积、原0.999近恒等初始化。固定输入/权重/梯度与冻结的beta源码参考一致，保留原融合与语义分支。全部门控参数进入optimizer、参与梯度、出现在FP32 EMA；初始第一层MLP零梯度符合末层零初始化，整体门控信号须非零有限。D1开启mask同步，但DC API不接收GT mask。marker=1残差checkpoint及无标识DC checkpoint被拒绝；新sigmoid marker=2；原生无DC预训练允许初始化新门控。
