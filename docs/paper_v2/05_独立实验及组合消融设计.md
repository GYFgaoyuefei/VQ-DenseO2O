# 独立实验及组合消融设计

主要实验仅B0/B1/G1/L1/D1 × seeds[0,42,3407]，第一批seed42共五次正式训练。B0→B1用于检查mask元数据路径的影响，G1/L1/D1各自与共同控制组对比。没有基于未运行实验宣称最佳模块。

B1使用原MAL和原矩形CopyBlend，额外mask不参与loss或网络。共享sanitize补齐元数据过滤，原RGB/bbox/class随机策略保持不变。固定种子单步几何等价不代表GPU训练全程逐位可复现；异步数据加载、GPU算子和训练状态可能影响长期轨迹，必须报告实际重复结果。

预留组合从同一个common.yml生成：
```bash
python tools/paper_v2/run.py generate-combinations
```

|组合|GR-VQ|LI-CopyBlend|DC-STA|mask|
|---|---|---|---|---|
|C1|开|开|关|开|
|C2|开|关|开|开|
|C3|关|开|开|开|
|C4|开|开|开|开|

文件位于configs/tomato/paper_v2/combinations/C1.yml到C4.yml。仅覆盖开关，不复制完整配方。resolver只选择一次数据类、一个collate实例和一个Criterion，因此不会重复读取mask/重复粘贴/重复质量调节。组合构造和合成单步可以检查，当前不启动组合正式训练。

后续子消融可在共同配置上显式切换 innovation.li_copyblend.illumination_sampling 或 foreground_only；必须独立命名输出目录并保存resolved config，不覆盖正式L1。DC α固定0.1，GR β固定0.10，不根据Test搜索。若未来改动实验预设，应在新实验中记录理由和统一控制变量。

公平性核对：同Train/Validation、同类别映射、同DINO/detector资源、同optimizer/FlatCosine、同增强窗口、同全局batch、同种子及同EMA Validation选模/tie规则。LI跳过会影响有效增强强度，必须同时报告attempted/accepted和skip统计。
