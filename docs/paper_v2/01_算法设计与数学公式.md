# Paper v2 算法设计与数学公式

本实现基于 paper_v2.0 的原生 DEIMv2-L。beta_select 仅用于阅读旧接口和 120e 配方；没有合并旧分支，没有沿用旧 VQ 公式或 Sigmoid DC 门控。

## 1. 模块位置

```text
Train COCO + genuine instance sidecar
  → 同步几何增强 / Mosaic
  → MixUp 或 CopyBlend（L1 用 LI-CopyBlend 替换此分支）
  → 当前增强后的归一化 RGB
  → DINOv3 ViT-S/16 blocks 5,8,11 → 384维语义 D
  → STA细节 S (64,128,128) → 可选 DC-STA(S,D,RGB)
  → concat[D,S'] → 原1×1投影 → 原SyncBN
  → 原Encoder / Decoder / Hungarian matching
  → 原L1、GIoU、FGL、DDF；普通MAL正样本可选 GR-VQ
```

GR-VQ 与 LI-CopyBlend 只在训练中使用。DC-STA 是 backbone 的组成部分，推理继续执行。没有 mask 预测 head。

## 2. GR-VQ

预测框 Bp、GT框 Bg 与实例二值 mask M 均处于当前增强后的相同图像坐标系。令 I(B,M)=|B∩M|，AM=|M|，AB=|B|：

- C(B,M)=I(B,M)/max(AM,ε)
- P(B,M)=I(B,M)/max(AB,ε)
- Crel=clip(C(Bp,M)/max(C(Bg,M),ε),0,1)
- Prel=clip(P(Bp,M)/max(P(Bg,M),ε),0,1)
- qgr=√(Crel·Prel)
- qiou=IoU(Bp,Bg)，采用普通 IoU，不使用 GIoU
- qgrvq=stop_gradient[qiou·((1−β)+β·qgr)]
- 普通匹配正样本 MAL 分类目标 t=qgrvq^γ

正式默认 β=0.10、γ=1.5、ε=1e−12。有效参考满足 Bp=Bg ⇒ qgr=1 ⇒ qgrvq=qiou，以及 (1−β)qiou≤qgrvq≤qiou。空 mask、非二值/非有限 mask、无效标志、无效 GT 参考直接回退 qiou。绝不生成 bbox 矩形伪 mask。

积分图在 float32 下构建。每个像素定义为 [x,x+1]×[y,y+1] 上的常数支持；对补零积分图做双线性连续边界插值，四角相减计算交集。交集限制在图像内，预测框面积保留图像外部分。默认以16个实例分块，避免同时构建过多积分图。所有质量函数 no_grad，预测框在转换前 detach。

普通 main / aux / pre / encoder 分支进入新质量；DN / DN-pre 直接原 MAL；β=0 在检查 masks 前直接原 MAL。匹配器、query selection、类别身份、负样本及其它损失不变。统计在设备上累计，epoch 边界汇总；DDP 对紧凑累计值求和。

## 3. LI-CopyBlend

A=illumination_sampling、B=foreground_only 可独立启停，正式 L1 两者均 true。

真实来源标签映射：natural=0、artificial=1、low_light=2、sodium_light=3、unknown=−1。只读取 COCO image metadata 或显式核实的 JSON 映射，不根据亮度/文件名猜类别。每个实例保存 source_illumination_id；Mosaic/MixUp 的 image_illumination_id 强制为−1，实例来源仍独立保留。

供体仅来自当前训练 batch 中带 source_is_train=true 的合法成熟度实例。要求合法 bbox、有效非空 mask、原 CopyBlend area_threshold，以及可裁剪的几何尺寸。没有跨数据划分的缓存供体池。

默认 light_policy=strict：可靠目标来源要求同光照；未知/混合目标依据粘贴邻域的背景统计判兼容，或跳过。prefer 优先同光照，异光照也必须通过局部背景兼容。局部统计排除全部已标注果实 bbox 和候选粘贴区域；对逆 Normalize 后 [0,1] RGB 的背景 RGB均值和亮度标准差比较，默认最大分量差≤0.20。不能把果实颜色差异当作光照差异。

公式：
Iout=(1−αMsrc)Idst+αMsrcIsrc。

实现用硬 mask 的 torch.where，保证 mask 外像素逐位不变。当前不做高斯扩散、色相映射或颜色迁移。供体/目标使用相同 Normalize，融合在该仿射归一化域执行，与 RGB 域融合代数等价；光度统计单独逆变换。

成功粘贴的 bbox 是移动后 mask 支持的紧致半开区间框 [xmin,ymin,xmax+1,ymax+1]，不额外扩一像素。area 保存新二值支持面积；iscrowd=0；类别和来源继承供体；blend_opacity 与二值 mask 分离。annotation_ids 为负数 PID+进程内计数器，区分原 COCO 正 ID 与运行期合成实例。固定种子复现 RGB/几何，运行唯一 ID 不要求跨进程相等。

默认 bbox/mask 冲突容忍度0，每个供体最多20次位置重试，每幅目标图供体尝试预算为 num_objects×max_donor_attempts（默认3×12）。已知严格光照不兼容的供体预先筛除。任何已有合法果实 bbox 都参与保护，即使其 mask 无效；有效 mask 即使延伸到旧 bbox 外也参与冲突保护。没有兼容供体/位置就跳过，不退回任意矩形粘贴。前景分支关闭的子消融可粘贴矩形，仍执行其矩形冲突检查。

## 4. DC-STA

从当前增强 RGB 逆 Normalize、clip[0,1]，自适应平均池化到80×80，构建8维 d：
亮度均值、标准差、sigmoid(12(0.2−Y))均值、sigmoid(12(Y−0.85))均值、R/G/B均值、水平/垂直绝对有限差分均值的平均。Y=0.299R+0.587G+0.114B。最后一项是空间有限差分，不是 FFT 特征。

每个尺度：
- gc=1+α tanh(MLP8→16→C(d))，MLP 中间 GELU
- U=concat[mean_channel(D),mean_channel(S),broadcast(d)]，共10通道
- gs=1+α tanh(Conv3×3,padding1(U))
- S'=S·gc·gs
- F=SyncBN(WD·D+WS·S')，代码保留原 semantic-first 拼接及同一个1×1投影

α固定0.1，不按Test搜索。最后Linear和空间Conv权重/bias全部零初始化，tanh(0)=0，因此初始两门严格=1，原细节和融合输出严格相同。每个门范围[0.9,1.1]，两门乘积范围[0.81,1.21]（考虑浮点舍入）。末层首步有梯度；上游MLP首步梯度可为零。
