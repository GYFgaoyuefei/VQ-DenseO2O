# 后续论文实验数据整理

当前没有新增真实训练AP、GPU效率或服务器结果，不填造任何指标。

每个run结束后保留完整目录，尤其config_resolved.yml、run_info.json、selection.json、epoch_validation.csv、best.pth和last.pth。记录实际数据版本与划分、类别表、光照映射来源、sidecar来源、训练硬件、环境和命令。run_info的资源路径是标识，不等同对权重内容的全量审计。

运行：
```bash
bash scripts/paper_v2/autodl/summarize_results.sh
```
汇总器只从真实存在的run_info提取Validation最优值与完成状态，缺失值留空，不补0，不生成不存在实验。summary.csv暂不把独立Test结果与Validation结果混为一列。

2026-10-19新增最终Test AP计算入口：`bash scripts/paper_v2/autodl/evaluate_and_summarize_ap.sh cuda:0 independent`，一次执行五组×三个seed的Mixed及四光照AP计算，并生成逐seed表、三seed均值和样本标准差。它使用Validation选出的EMA best.pth，不启动训练。离线重汇总用`summarize_ap.sh`；完整命令、光照映射、缺失值和效率主表合并见`10_Test_AP计算与三seed汇总.md`。

建议最终论文记录字段：
|分组|记录内容|
|---|---|
|身份|model、seed、commit、配置路径、资源标识|
|Validation|EMA最佳epoch、AP、AP50、AP75、APS/APM/APL|
|固定Test|独立评估时间、选用best checkpoint、AP及尺度/类别/真实光照分组|
|GR诊断|qiou/qgr/qgrvq均值、valid mask比例、fallback数、saturation比例、正目标均值|
|LI诊断|attempted/accepted、invalid mask/light/collision/location跳过、前景覆盖比|
|效率|固定FP32部署协议；Full/Deploy Params、deploy-forward GFLOPs及PARTIAL覆盖证据；独立实测forward+postprocessor主延迟、forward-only、postprocessor-only、P50/P95、显存峰值；每seed 5×(100预热+500计时)|
|重复性|三个seed原始值、均值、样本标准差、未完成/失败原因|

训练原生log.txt中的train_gr_vq_*为epoch汇总。train_copyblend_*对原生及LI均记录新增GT，LI配置另有train_li_*。接受率由全epoch累计accepted/attempted计算；added_instances_per_image和foreground_area_ratio按全部训练图像数归一化，包含未抽中增强及关闭阶段。碰撞/光照计数可按重试/供体过滤累计，不应直接把所有skip项相加等同attempted_pastes。

仅在所有计划种子完成且评估协议一致后计算均值/标准差。Test不参与beta/alpha/阈值/选模决策。精度/速度改善需要真实结果支持；当前实现正确性测试不能证明论文性能提升。

效率结果统一放在 outputs/paper_v2/efficiency/。先平均每seed五轮延迟，再计算三个seed的均值及样本标准差；FPS=1000/对应平均Latency(ms)。论文Params(M)固定使用Deploy Params(M)。paper_efficiency_table.csv保留原列序：Model、Epoch、Params(M)、GFLOPs、Latency(ms)、FPS、Hardware，随后Mixed COCO指标和四光照AP，再附效率审计字段。没有真实测量时效率保持空值/NOT RUN；calflops缺失时GFLOPs为空，算子覆盖未证实时明确PARTIAL。

已独立评估的AP可通过 --ap-csv 显式合并；格式和百分数单位见08_统一效率统计协议.md。汇总器不会运行COCO evaluator、不会读取Test选模，也不会自动把Validation AP填入Mixed Test AP。英文论文方法段落见09_Efficiency_Evaluation_Protocol.md。
