# Paper v3.0 算法实现说明

日期：2026-10-19。开发分支为 `paper_v3.0`；`beta_select` 仅作算法参考，未合并整个分支。为沿用现有工具链，配置、脚本与文档继续使用 `paper_v2` 目录名。新实验输出根目录为 `outputs/paper_v2_beta_select_algorithms/`，旧实验结果不迁移、不重命名。

本轮正式模块为 **VQ-DenseO2O、LI-CopyBlend、DC-STA**。GR-VQ、GT-referenced normalization、残差 tanh 门控均不属于本轮正式训练路径。算法参考为 `beta_select` 提交 `f92edb021fd468e354f5767bb81ac745e0347cfe`。

## 1. Baseline 与公共训练算法

Baseline 使用 DEIMv2-L：DINOv3 ViT-S/16 提取第 5、8、11 个索引位置的语义特征；原 STA 生成步长 8、16、32 的细节特征。每级按 `[semantic, detail]` 顺序拼接，经过原 `1×1 Conv` 和 `SyncBatchNorm`，输出 224 通道特征，再进入原 HybridEncoder 与 DEIMTransformer。没有新增 mask 预测头。

实现入口：

- `engine/backbone/dinov3_adapter.py`：`SpatialPriorModulev2`、`DINOv3STAs` 及原融合顺序。
- `engine/deim/hybrid_encoder.py`、`engine/deim/deim_decoder.py`：编码器和检测 Transformer。
- `engine/deim/deim_criterion.py`、`engine/deim/matcher.py`：原 DEIMCriterion、MAL 和 HungarianMatcher。
- `engine/data/dataloader.py`：原 MixUp、矩形 CopyBlend 调用及其调度。
- `configs/tomato/paper_v2/common.yml`：所有新实验共享的有效配置母版。

普通 Baseline MAL 对匹配正样本使用预测框与 GT 框的真实 IoU：`t_positive = stop_gradient(q_iou)^1.5`。类别身份、负样本权重、匹配、定位损失及损失归一化沿用原实现。为扩展 VQ，仅给 criterion 调用补充普通分支与 DN 分支的路由标记；关闭 VQ 时该标记不改变原损失计算。

本轮共同采用 120 epochs、seeds `0/42/3407`、640×640 输入、3 类、有效训练 batch 32、AdamW、EMA，以及统一的增强调度和学习率调度。所有模型使用相同 DINOv3 权重与 detector 预训练权重。训练可使用公共 AMP 配置；最佳 checkpoint 一律由 **EMA FP32 Mixed Validation AP** 选择，AP 相同保留较早 epoch。公共训练协议及其与旧实验的差异见迁移说明，不能将旧 Baseline 结果直接拼入本轮结果。

## 2. B0/B1 与实例字段同步

| 配置 | Dataset | mask 的用途 | Criterion |
|---|---|---|---|
| B0 `baseline_native` | `CocoDetection` | 不加载实例 mask | 原 `DEIMCriterion` |
| B1 `baseline_maskaware` | `VisibleMaskCocoDetection` | 仅加载及同步实例元数据 | 原 `DEIMCriterion` |

B1-C4 共用一次实例 mask 加载与同一条几何传播路径。MixUp、Mosaic、CopyBlend、Crop、Resize、Sanitize 后同步检查 `boxes`、`labels`、`masks`、`area`、`iscrowd`、`annotation_ids`、`visible_mask_valid`、`source_illumination_id`。实例过滤统一作用于所有实例字段，图像级字段不按实例误删。

同步实现位于 `engine/data/visible_geometry.py`、`engine/data/dataset/visible_coco_dataset.py` 和对应 transform/collate 路径。mask 是二值几何支撑，不能以混合透明度替代；透明度单独记录。mask 缺失、为空或无效只影响其有效标识，不能据此删除本来合法的 bbox。B1 使用原生 CopyBlend，不用 mask 改写 RGB 融合方式，也不用 mask 改写 MAL 软目标。

## 3. VQ-DenseO2O：原始前景质量监督

实现：`engine/deim/vq_quality.py`、`engine/deim/vq_criterion.py`。正式配置字段与独立模型标识统一为 `vq_dense_o2o`。配置解析器强制本轮 `beta = 0.10`；原 MAL 指数为 `gamma = 1.5`。

对于普通匹配正样本，设二值 GT 可见实例 mask 为 `M`，预测框为 `B_pred`：

\[
C=\frac{|M\cap B_{pred}|}{|M|},\qquad
P=\frac{|M\cap B_{pred}|}{|B_{pred}|},\qquad
q_{fg}=\sqrt{CP}.
\]

以预测框与 GT 框的真实 IoU 为 `q_iou`：

\[
q_{vq}=\operatorname{stopgrad}\left(q_{iou}\left[(1-\beta)+\beta q_{fg}\right]\right),
\quad \beta=0.10,\qquad
t_{positive}=q_{vq}^{1.5}.
\]

保留 `beta_select` 的连续坐标积分图算法：预测框从归一化 `cxcywh` 转成连续像素坐标；对 padded 二维积分图作边界双线性求值，得到包含分数像素贡献的交集。积分位置裁剪至 mask 画布，而 **Purity 分母保留预测框未裁剪的连续面积**。Coverage、Purity 均按原实现限制在 `[0,1]`，分母使用原 `1e-12` 下界。不能以整数 floor/ceil 框替代该积分，也不能擅自将分母改为裁剪后的框面积。

连续 mask 积分与 `q_fg` 使用 FP32；送入原 MAL 前按原实现对齐 IoU/分类目标 dtype。质量分支在 `no_grad` 下计算，不能通过质量目标向框回归或 mask 反传。无效标识或空 mask 对该正样本回退到原 IoU 目标，即 `q_vq = q_iou`；不是将无效样本质量清零。缺失整套同步字段属于数据管线错误，会显式报错。`boxes_weight_format=giou` 不允许用于 VQ，避免把 GIoU 误当成 IoU。

| 路径 | VQ 是否修改 |
|---|---|
| 普通 main、aux、pre、encoder 分支的正样本 MAL 目标 | 是 |
| 负样本 target、类别编号 | 否 |
| Hungarian matching、query selection | 否 |
| DN、pre-DN 分类与定位 | 否 |
| bbox L1、GIoU、FGL、DDF | 否 |
| 推理 forward、postprocessor | 否 |

`VQDEIMCriterion` 只将校准后的 `values` 交给父类原生 MAL；其余损失继续调用原实现。没有 `C_pred/C_gt`、`P_pred/P_gt`、`q_gr` 或 GT-referenced normalization。VQ 推理不加载 mask，不计算前景质量。

有效性诊断按普通匹配正样本累计：`valid_mask_ratio`、`fallback_ratio`、`q_iou_mean`、`q_fg_mean`、`q_vq_mean`、`q_fg_near_one_ratio`、`positive_target_mean`、`target_delta_from_native_mal`。其中 `q_fg` 统计排除无效 mask，fallback 与目标差值统计覆盖全部普通匹配。具体数值对照结果见算法正确性测试报告，本说明不替代实测结果。

## 4. DC-STA：恢复原 Sigmoid 门控

实现：`engine/backbone/dc_sta.py`，由 `DINOv3STAs` 在原 STA 与融合层之间调用。D1 的数据配置开启 `instance_mask_sync=true`，但 DC-STA 的函数输入只有 RGB、语义特征和 STA 细节特征；不接收 targets 或 GT mask。

### 八维退化统计描述符

先将当前增强后的输入按原 ImageNet Normalize 参数反归一化，裁剪到 `[0,1]`，再自适应平均池化至 80×80。亮度为 `Y = 0.299R + 0.587G + 0.114B`。描述符的八个分量依次为：

1. `mean(Y)`。
2. `sqrt(var(Y, unbiased=False) + 1e-8)`；保留原边界处理，常量图对应 `1e-4`，不是严格零。
3. `mean(sigmoid(12 × (0.2 − Y)))`。
4. `mean(sigmoid(12 × (Y − 0.85)))`。
5. `mean(R)`。
6. `mean(G)`。
7. `mean(B)`。
8. 水平、垂直相邻亮度绝对差均值的平均值。

最后一个分量是有限差分高频代理，不是 FFT 特征。描述符按原实现以 FP32 计算；统计项开关、非有限值检查保留原行为。

### 通道与空间门控

每个尺度通道分支为 `Linear(8,16) → GELU → Linear(16,C_l)`；局部分支输入为语义特征通道均值、STA 特征通道均值及广播后的八维描述符，共 10 通道，再用 `Conv2d(10,1,3,padding=1)`：

\[
g_c=\sigma(f_c(d)),\qquad g_s=\sigma(f_s([\overline{F},\overline{S},d])),\qquad
S'_l=S_l\odot g_c\odot g_s.
\]

仅调节 STA 细节分支；DINOv3 语义特征保持原值。之后仍按 `[semantic, modulated_detail]` 拼接，使用原 `1×1 Conv`、SyncBN，输出尺寸不变。

共同配置开启两种门控，`init_detail_gain=0.999`。每个门控的初始概率为 `p=sqrt(0.999)`，MLP 末层与空间 Conv 的权重初始化为零，bias 为 `log(p/(1-p))`，故初始门控乘积约为 `0.999`。配置字符串 `gate_init: identity` 是原实现保留的历史名称，**不表示严格恒等 1**。本实现没有 `1+alpha*tanh(...)`，也没有 DC `alpha=0.1` 参数。

模块构建保持原随机数隔离，使增加门控不会移动其他检测器参数的初始化 RNG。新增门控参数进入 optimizer 与 FP32 EMA，训练诊断检查覆盖、缺失/非有限梯度和总体梯度范数。由于末层权重初始为零，第一次 backward 时通道 MLP 第一层梯度为零符合原结构；不能将这一点误判为整模块不参与训练。

checkpoint 使用整数 buffer `_gate_architecture=2` 标识本轮恢复的 Sigmoid 结构。旧 residual-tanh 的标识 `1`、无标识历史 DC 权重均不能直接作为本轮训练恢复状态。统一原生 detector 预训练不含 DC 子树，可以正常加载并保留新的近恒等初始化；本轮新训练必须重新产生自己的 optimizer、EMA 和选择记录。该标识仅用于简洁的结构检查，不更改门控公式。

## 5. LI-CopyBlend：保留现有前景融合与光照规则

实现：`engine/data/li_copyblend.py`，调用点保留在 `engine/data/dataloader.py` 原 CopyBlend 随机选择和 epoch 时间表内。共同配置使用 `light_policy=strict`、`foreground_only=true`、局部光度检查及零碰撞容忍。关闭 LI 时走原矩形 CopyBlend；因此 B0、B1、V1、D1 均不使用 LI 前景融合。

供体来自当前训练 batch 的合法 Train 实例；要求有效非空 mask、合法类别与 bbox、面积满足原阈值。已知光照的目的图按实例来源光照筛选供体；未知或混合光照来源通过现有局部背景统计规则判定兼容性。局部统计先反归一化到 RGB，排除候选区域和所有已有果实框，背景不足时拒绝候选。不会根据番茄外观重新推断成熟度类别或拍摄光照标签。

对平移后的硬前景 mask `M`、供体像素 `I_s`、目的像素 `I_d`，沿用：

\[
I'=I_d+\lambda M\odot(I_s-I_d).
\]

`lambda` 沿用原 CopyBlend 混合比例；这与被取消的 DC 残差缩放参数无关。实现以 `torch.where` 保证 mask 外像素逐值不变，mask 内进行既定 RGB 线性融合。共享的仿射 Normalize 空间下执行该线性融合与 RGB 域等价；光度兼容检查始终在反归一化 RGB 域完成。

碰撞检查同时考虑已标注 bbox 与有效 mask 支撑，避免覆盖现有果实。接受粘贴后更新前景紧致框、二值 mask、前景面积、类别、`iscrowd`、实例 ID、透明度及来源光照等字段，保留原字段同步约束。一次组合实验仅调用一次该增强，不因同时启用 VQ/DC 重复加载 mask 或重复融合。

保留 `attempted_pastes`、`accepted_pastes`、`acceptance_ratio`、`added_instances_per_image`、`skipped_by_light`、`skipped_by_collision`、`skipped_by_invalid_mask` 诊断。比例按累计计数计算；重试和供体过滤可能分别记录拒绝事件，拒绝计数不应强行解释为互斥的尝试终态。

## 6. 正式入口约束与验证边界

`engine/core/innovation_config.py` 负责开关到真实 Dataset、Criterion、DC 和 LI 组件的解析。B0 关闭全部模块和 mask 同步；B1 只开启 mask 同步；其余正式模块均依赖同一 mask-aware 数据路径。原 `gr_vq` 字段及 DC `alpha` 会显式拒绝，不作为隐式兼容默认项。

九组配置及完整 `2^3` 因素设计见配置矩阵文档；非创新训练参数必须相同。确定性测试分别核对 beta Baseline、mask 数据路径、VQ 原公式、DC 原门控和 LI 原规则。DC 原始类的冻结参考在 `tests/paper_v2/references/beta_dc_sta.py`，用于固定初始化、固定权重/输入、输出与梯度的数值对照，不用于加载历史训练 checkpoint。

本阶段只执行合成数据及有限冒烟检查，不启动完整 120 轮训练，不访问 Test。依赖 AutoDL 数据或正式 GPU 的检查应在测试报告中明确标记 `NOT RUN`；合成检查不能代表真实训练收敛或论文 AP。
